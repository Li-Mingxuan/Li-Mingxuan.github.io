# Mingxuan Li · Academic Homepage

Personal academic website: https://li-mingxuan.github.io/

Research interests: underwater acoustic communication, semantic communication, and underwater target recognition.

The current website uses [luost26/academic-homepage](https://github.com/luost26/academic-homepage), retaining its original white/gray appearance, Lato font, and blue links.

## Current website source

`academic-homepage.zip` contains the complete editable Jekyll source. The Pages workflow extracts it into `site/`, builds it with Jekyll, and publishes `site/_site/`.

To edit the site, extract the archive and update `_data/profile.yml` (profile, education, and CV) or `_data/research.yml` (interests and research projects). Publication entries belong in `_publications/`. Repackage the archive with `_config.yml` at its root and upload the revised archive to trigger deployment.

The earlier Academic Pages template files are retained in this repository for reference. They are not part of the current deployment. Repository history preserves the earlier version.

The original private CV document is not included. Publication records and the portrait will be completed separately.
